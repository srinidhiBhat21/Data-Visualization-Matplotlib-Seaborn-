# Data Visualization using Matplotlib & Seaborn

## Project Overview

This project focuses on exploring different data visualization techniques using Python's Matplotlib and Seaborn libraries.

The Seaborn Tips dataset was used to create different charts and understand distributions, comparisons, relationships, and correlations between variables.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Visualizations Performed

### 1. Histogram
- Created histograms using Matplotlib and Seaborn.
- Analyzed the distribution of total bills.

### 2. Bar Chart
- Compared average tips across different days.
- Used Matplotlib and Seaborn for visualization.

### 3. Box Plot
- Visualized the distribution of total bills.
- Compared total bill distributions across different days.
- Identified potential outliers.

### 4. Scatter Plot
- Explored the relationship between total bills and tips.
- Used gender-based color grouping in Seaborn.

### 5. Correlation Heatmap
- Calculated correlations between numerical columns.
- Created heatmaps using Matplotlib and Seaborn.

## Additional Tasks

- Customized chart titles and axis labels.
- Adjusted font sizes and figure dimensions.
- Experimented with different color palettes.
- Saved a histogram as a PNG image using `plt.savefig()`.

## Key Learnings

- Understanding different types of data visualizations.
- Working with Matplotlib and Seaborn.
- Comparing categorical and numerical variables.
- Identifying distributions, relationships, and correlations.
- Customizing and exporting visualizations.

## Conclusion

This project helped me gain practical experience in creating and customizing different visualizations using Matplotlib and Seaborn. It also improved my understanding of how visual representations make data easier to interpret.
